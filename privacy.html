プライバシーポリシー

最終更新日: 2026年11月24日

本ポリシーは、YouTube チャンネル「日本人がまだ知らない世界」（@katahaba-golf）の運営者が使用する動画投稿ツール「AutoShorts Uploader」（以下「本ツール」）における情報の取り扱いを定めるものです。

1. YouTube API サービスの利用

本ツールは YouTube API サービスを使用しています。本ツールを利用することで、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いについては Google プライバシーポリシーをご確認ください。

2. 取得する情報

  • 本ツールが要求する権限は、運営者自身の YouTube チャンネルへ動画をアップロードする権限（youtube.upload）のみです。
  • 認証により発行されるアクセストークンは、運営者のパソコン内にのみ保存し、外部に送信しません。
  • 視聴者や第三者の個人情報を取得・保存することはありません。

3. 情報の利用目的

取得した権限は、本ツールで作成した動画を運営者のチャンネルにアップロードする目的にのみ使用します。

4. 第三者への提供

Google ユーザーデータを第三者に販売・共有・提供することはありません。本ツールによる Google API から受け取った情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

5. 保存と削除

アクセストークンは本ツールの動作に必要な期間のみ保存します。連携は Google アカウントのセキュリティ設定からいつでも解除でき、解除後は保存したトークンを削除します。

6. Cookie 等

本ツールおよび本サイトは、Cookie やトラッキング技術を使用しません。
