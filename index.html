🌍 日本人がまだ知らない世界

中央アジア、アフリカ、南米、ヒマラヤなど、日本ではなかなか見る機会のない国の暮らしを、日本語字幕つきのショート動画で紹介する YouTube チャンネルです。

チャンネル: https://www.youtube.com/@katahaba-golf

AutoShorts Uploader について

AutoShorts Uploader は、上記チャンネルの運営者が自分のパソコンで使う、個人用の動画制作・投稿ツールです。

  • クリエイティブ・コモンズ 表示（CC BY）ライセンスで再利用が許可された動画の一部を切り出し、日本語字幕を付けたショート動画を作ります。
  • YouTube Data API を使い、完成した動画を運営者自身のチャンネルにアップロードします。
  • 各動画の説明欄に、元動画・制作者・ライセンスを記載します。

このツールは一般公開しておらず、運営者以外の Google アカウントへのアクセスは求めません。
